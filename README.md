Problem Statement

Cardiovascular diseases are one of the leading causes of death worldwide. Early detection is critical, but many screening systems require expensive medical tests and expert interpretation. Rural and resource-limited healthcare settings often lack access to advanced diagnostic tools.

This project aims to develop an AI-based system that predicts cardiovascular disease risk using low-cost clinical and lifestyle data. The system provides early risk assessment and explainable insights to support preventive healthcare decisions.
